# 🚀 AuraPredict AI — Customer Churn Prediction & Automated Retention SaaS

**Live Application:** [https://aurapredict-ai-saas-ry5t.bolt.host](https://aurapredict-ai-saas-ry5t.bolt.host)

AuraPredict AI is a lightweight, full-stack B2B analytics web application designed for Indian MSMEs, D2C brands, and subscription startups to transform messy transaction CSVs into actionable customer retention workflows.

---

## 💡 Key Features

- **Automated CSV Data-Cleaning Pipeline:** Ingests raw billing CSVs in real time, detects formatting anomalies, removes zero-billing records, handles missing values, and computes a live **Data Quality Score**.
- **RFM Statistical Modeling Engine:** Evaluates every customer across **Recency, Frequency, and Monetary (RFM)** parameters to dynamically segment accounts into **High, Medium, and Low Churn Risk** tiers.
- **Executive Analytics Dashboard:** Dark-themed responsive UI displaying Cleaned Data Records, Revenue at Risk, and Churn Distribution visual metrics.
- **One-Click Retention Workflows:** Simulated WhatsApp/SMS automated retention triggers tailored for high-risk customer cohorts.

---

## 🛠️ Tech Stack

- **Frontend & UI:** Next.js, React.js, TypeScript, Tailwind CSS, Lucide Icons
- **Data Processing & Logic:** Browser FileReader API, Algorithmic Data Sanitization, Statistical RFM Scoring Engine
- **Rapid Prototyping & Deployment:** Bolt.new, v0.dev
